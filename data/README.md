# data/

Pre-existing dataset and generated artefacts used by WhyTrace.

## Pre-existing

`turkish_phishing_dataset.csv` — **Turkish Phishing Email Dataset**, published
by the builder (Osman Can Çetlenbik) on Kaggle in Feb 2025
(`osmancancet/turkish-phishing-email-dataset`). 7,504 rows, two Turkish-labelled
classes (Oltalama 6,004 / Güvenilir 1,500). Licence: **CC BY-NC-SA 4.0** —
non-commercial, share-alike. The hackathon use is non-commercial.

Used in Zetaris as the file-store table `FILES.phish_corpus`; the Investigator
agent references it as a governed template corpus, **not** as a classifier
training set (the dataset is templated and would score ~100% trivially; see
`notes/SPEC.md` §11).

## Generated by `npm run seed`

- `assets.csv` — asset inventory for the Zetaris file store.
- `mailgw/{deliveries,clicks,rules}.json` — snapshot payloads served by
  the mailgw mock in `services/mailgw`.
